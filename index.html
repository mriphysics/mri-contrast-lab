03

About the model

What is being simulated?

Anatomy

BrainWeb phantom

The anatomy comes from the BrainWeb simulated brain database. It is fitted proportionally into a zero-padded 256 × 256 matrix with eleven tissue classes plus background.

Relaxation

T1, T2 and T2*

Each class is assigned simplified relaxation times for teaching. These rough values should not be used as quantitative tissue references.

Noise

One fixed noise image

The same Gaussian noise pattern and amplitude are added in every mode, making low-signal acquisitions appear visibly noisier.

About the FLAIR model

FLAIR is represented as a spin-echo signal preceded by inversion. Adjust TI to find where a tissue’s longitudinal magnetisation crosses zero; the displayed image uses magnitude, matching the original Live Script.
